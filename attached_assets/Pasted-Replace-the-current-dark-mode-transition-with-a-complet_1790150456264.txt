## Core Concept

When the dark-mode button is clicked, the page should feel like a wave of dark glass/light is passing through the interface.

Imagine a transparent refractive energy wave moving diagonally across the screen.

The existing page stays visible underneath the entire time.

As the wave passes over each section:

light theme
→ subtle distortion/glow
→ dark theme

It should look like the theme is physically traveling through the website rather than the website disappearing and reloading.

## Visual Sequence

When switching to dark mode:

1. User clicks the moon icon.

2. The icon emits a very small pulse.

3. A thin luminous wave begins near the toggle.

4. The wave travels diagonally across the viewport.

5. As the wave crosses elements, their colors transition from light to dark.

6. Text, cards, buttons, images, navbar and page content stay visible.

7. The wave leaves a subtle darkened glass-like surface behind it.

8. The effect finishes with a tiny ambient glow near the toggle and disappears.

The wave should look somewhat like:

LIGHT UI

────────────╲
             ╲
              ╲   ← moving refractive wave
               ╲
                ╲

DARK UI behind the wave

But this should be organic and soft, not a hard straight line.

## Refraction Band

Create a moving band approximately:

100–180px wide

- subtle blur
- slight brightness shift
- faint glass refraction
- a soft highlight along the leading edge
- slight contrast increase

Suggested effects:

backdrop-filter:
blur(4px) brightness(1.05)

opacity:
0.15–0.30

Use very subtle values.

## Organic Shape

The wave should NOT be a simple rectangle.

Give it an irregular, slightly curved or liquid edge using:

- CSS mask
- radial gradients
- multiple layered gradients
- pseudo-elements

The edge should feel organic, like moving glass or liquid light.

Avoid overly dramatic liquid animations.

## Theme Transition Behavior

The dark theme itself should transition progressively.

Do not wait until the animation finishes before applying dark mode.

Instead, coordinate the theme change with the moving wave so it visually appears that the dark mode is being revealed behind it.

The page should never become blank.

All visible elements must remain rendered.

## Optional Depth Effect

During the transition, apply a very subtle depth response to nearby elements.

For elements close to the moving wave:

transform:
translateZ(0) scale(1.003)

or a tiny 1–2px visual shift.

Do not move layout positions.

Do not create shaking or snapping.

The effect should be barely noticeable but make the wave feel physical.
