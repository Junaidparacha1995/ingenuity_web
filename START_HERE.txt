INGENUITY SYSTEMS — START HERE

Recommended VS Code run method (clean URLs + forms + chatbot backend):

1. Open this entire folder in VS Code.
2. Open Terminal > New Terminal.
3. Run: npm install
4. Copy .env.example to .env (the Windows launcher does this automatically).
5. Run: npm start
6. Open: http://localhost:3000

Windows shortcut: double-click run-windows.bat
macOS/Linux: ./run-mac-linux.sh

IMPORTANT:
The site now uses clean routes such as /services/ai and /projects instead of showing .html in the browser URL. Because of this, use the Node server above instead of VS Code Live Server for normal testing.

For the professional RAG chatbot, add OPENAI_API_KEY to .env and run npm run setup:rag once before npm start.
Never put API keys in HTML or browser JavaScript.
