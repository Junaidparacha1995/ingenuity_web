# V6 Production Engineering Notes

V6 is primarily an engineering hardening release rather than another visual-effect release.

Key production changes: semantic landmarks, consolidated navigation, CSS layering, real contact API, opt-in first-party analytics, embedded booking, RAG knowledge correctness, idempotent RAG syncing, source links, request IDs, rate limits, CSP, compressed responses, restricted public file serving, responsive image attributes, dynamic SEO, sitemap/robots, proper 404 handling, GitHub metadata caching, and automated structural auditing.

The remaining launch-specific inputs are intentionally externalized into `.env` or approved content: real domain, lead/CRM destination, verified client proof, and team photography.
